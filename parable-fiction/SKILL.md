# 超短篇哲学寓言小说创作指南

## 一、理解这种体裁

超短篇哲学寓言小说是一种以**具体感官经验承载抽象命题**的文体。它不是在讲道理，而是在构建一个**可以让读者亲身进入的处境**，让命题从处境内部自然生长出来。

核心特征：
- **篇幅**：800—2500 字之间。太短成格言，太长成普通短篇。
- **人物**：极简，通常 1—2 个，名字可以缺失或高度象征化（「男孩」「女人」「他」）。
- **时间**：压缩或悬置，不追求真实世界的时间流动。
- **空间**：虚构或去地名化，但感官细节必须真实可触摸。
- **结局**：开放式为主。寓言的意义在于悬而未决，不在于给出答案。

参照谱系（创作时心里可以有这些坐标）：
- 卡夫卡（荒诞的官僚处境，绝对严肃的语气）
- 博尔赫斯（迷宫、镜像、无限，智识密度极高）
- 加缪《西西弗神话》散文化段落（存在主义情绪，但保持冷静）
- 川端康成早期掌小说（感官细节，余韵绵长）
- 中文参照：史铁生《我与地坛》里的哲思散文段落、迟子建的意象密度

## 二、创作前的核准步骤

拿到用户的主题/命题后，先在内部做以下判断：

### 1. 提炼「核心困境」
把用户给的主题压缩成一句话：**「一个人面对……，他/她无法……，但又不得不……」**

示例：  
用户主题：「神放了两棵树，找到树能多活，但男孩不知要不要找第二棵」  
核心困境：「一个人得到了足够的，却不知道「足够」是否真的足够」

这个句子是整篇故事的重力中心，所有意象、场景、节奏都围绕它旋转。

### 2. 找到「载体意象」
核心困境需要一个具体的物质形象来承载，不能是概念直接出场。

问自己：**这个困境在现实物质世界里，最接近什么东西的形态？**

| 困境 | 可能的载体意象 |
|------|--------------|
| 选择的代价 | 岔路上的石子、天平、两扇门 |
| 时间的流逝 | 沙漏、逐渐褪色的墨水、融化的东西 |
| 已知与未知 | 上锁的柜子、未翻开的地图、雾 |
| 「足够」的问题 | 装满的碗、找到的树、已到达的彼岸 |

意象一旦确定，必须贯穿全文。**不要在一篇故事里放超过两个核心意象**，否则焦点涣散。

### 3. 决定叙事视角与距离
- **第三人称限知**：最常用。「他/她」，跟随人物内心，但叙述者保持克制的距离感。适合哲学困境。
- **第二人称**：代入感强，但用不好会有压迫感，谨慎使用。
- **第一人称**：适合带个人化抒情色彩的寓言，类似散文化处理。

## 三、结构模板

超短篇哲学寓言通常遵循以下内在节奏，篇幅分配仅供参考：

```
[降落]        约 10—15%
设置世界的基本规则。语气必须稳、冷、精准。
不要解释太多，抛出一个奇异但内部自洽的设定。
读者需要感受到：这个世界有它自己的重力。

[遭遇/行动]   约 30—40%
人物与这个世界/困境发生接触。
此处应有具体的感官细节——气味、温度、声音、触感。
哲学命题必须通过行动和感知呈现，不能由叙述者直接说出来。

[内部震荡]    约 25—35%
人物内心的纠结、停顿、自问。
这是整篇文章哲学浓度最高的部分。
但要克制——用意象和行为暗示，少用思想的直接呈现。
可以加入一个「旁观者」：动物、陌生人、一个物件，提供外部视角。

[开放的动作]  约 15—20%
人物做出某个动作（或拒绝做出动作）。
这个动作不解决任何问题，但它代表人物在此刻的选择。
结尾必须留有空气——一个悬置的意象，一句不闭合的话，或者干脆留白。
```

## 四、语言风格指令

### 句式
- 优先使用**短句和中句交替**的节奏。长句用于沉思段落，短句用于动作和转折。
- 避免四字成语堆砌（显得古板），避免网络口语（破坏质感）。
- 对话尽量少，有对话时要有分量，每句都要「值得说」。

### 意象处理
- 意象出现时，**给它具体的物理属性**：颜色、温度、重量、声音。不要只说「美丽的树」，要说「树干是深紫色的，叶片细长，风吹过发出嘘的声音」。
- 同一个意象在文中**最多出现三次**，每次出现都要有微小的变化，暗示主题的推进。

### 叙述者的态度
- 叙述者应该**平静而非全知**。哲学寓言最忌讳叙述者替读者下结论。
- 遇到最核心的命题时，叙述者可以沉默，让人物的身体动作说话。

### 禁止清单
- ❌ 直接说出寓言想表达的道理（「这告诉我们……」）
- ❌ 角色做梦然后梦解释了一切（梦可以用，但不能承担解题功能）
- ❌ 结尾用感叹句或反问句收尾（廉价的情绪提升）
- ❌ 每个意象都加修饰词（「美丽的」「深沉的」「令人感叹的」）
- ❌ 背景交代超过全文的 15%

## 五、参考文风样本（可选读）

如果用户提供了参考文风（如对话历史里出现了范文），先提取以下信息再创作：

1. **句子平均长度**：短/中/长？是否有意识地在段落内部制造节奏变化？
2. **意象密度**：每段大概几个具体意象？
3. **叙述者距离**：冷静旁观型，还是情绪渗入型？
4. **结尾处理**：收束感强，还是刻意留白？

把这四个维度记住，在写作时有意识地对齐。

## 六、完整创作流程

```
1. 收到主题/命题
   ↓
2. 内部提炼「核心困境」（一句话）
   ↓
3. 确定「载体意象」（1—2个）
   ↓
4. 决定视角、篇幅、参考文风
   ↓
5. 按结构模板写作
   （降落 → 遭遇 → 内部震荡 → 开放的动作）
   ↓
6. 完稿后自查：
   - 有没有直接说出道理？→ 删掉
   - 结尾有没有真正留白？→ 确认
   - 核心意象有没有贯穿全文？→ 确认
   - 是否有超过两段的纯内心独白？→ 压缩或替换为行为
```

## 七、边界说明

此 skill 适用于：
- 以哲学命题/思想实验为出发点的虚构短篇
- 魔幻现实主义、荒诞主义风格的超短篇
- 用寓言形式探讨存在、选择、时间、语言、意义等主题

不适用于：
- 有完整情节弧、人物成长、冲突解决的常规短篇小说（请使用其他 skill）
- 散文诗（结构和侧重点不同）
- 非虚构哲学写作
